# PC Build Planner

## Group Members
- Aaron Gravelle

## Project Description
PC Build Planner is a Next.js application that helps beginners learn about PC components and build a custom computer based on their budget and needs.

## User Stories

- As a beginner, I want to learn what each PC component does.
- As a user, I want to browse recommended builds.
- As a user, I want to compare components.
- As a user, I want to save a build plan for later.

## Project Setup
Created the Next.js application using TypeScript and ESLint. Initial project planning and task board completed.
